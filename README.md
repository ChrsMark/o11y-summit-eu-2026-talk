# From Schema to Shipping Data: Making OpenTelemetry Stable by Default

Talk by **Christos Markou** (Elastic) and **Pablo Baeyens** (Datadog)
at [Observability Summit Europe 2026](https://events.linuxfoundation.org/observability-summit/) — October 5, Prague.

## Abstract

OpenTelemetry has grown into the second-largest CNCF project, yet two of its most critical
components — Semantic Conventions and the Collector — are still finding their way to stability.
This talk covers the real-world pain of unstable schemas, the RFC-driven migration mechanism
that solved it, and what "stable by default" means for the ecosystem going forward.
